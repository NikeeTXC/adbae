# Fish It Script

This is an automated fishing script for Roblox "Fish It".

## Features
- **Auto Fishing**: Automatically catches fish.
- **Auto Sell**: Automatically sells fish when inventory is full or after a certain time.
- **Teleport**: Teleport to various fishing locations.
- **Webhooks**: Discord webhook support for rare catches, player logs, and admin notifications.
- **Anti-AFK**: Prevents disconnection due to inactivity.
- **Walk on Water**: Allows walking on water surface.
- **Performance**: Options to disable animations and VFX for better performance.

## Usage
Execute the script using your preferred Roblox executor.

## Configuration
The script saves configuration in `XAL_Configs` folder in your workspace.
